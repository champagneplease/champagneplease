## Sobre mí

Desarrollador Backend enfocado en el diseño y desarrollo de aplicaciones escalables.

Actualmente en formación, consolidando habilidades en desarrollo de APIs y arquitectura backend.

- **Desarrollo Backend:** Desarrollo de servicios y APIs con `Python` (Flask, Django, FastAPI) y `Node.js` / `JavaScript` (Express, NestJS).

- **Bases de Datos:** Diseño y gestión de bases de datos relacionales (`PostgreSQL`) y no relacionales (`MongoDB`).

- **Infraestructura:** Manejo de terminal en entornos **macOS** y **Linux**, con uso de contenedores (`Docker`) en entornos de desarrollo.

- **Herramientas IA:** Uso de asistentes de código enfocado en productividad y automatización de tareas.

- **Frontend:** Conocimientos básicos en `React` para asegurar una correcta integración con el backend.
